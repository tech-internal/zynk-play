🛠️ IF YOU SEE A BLANK PAGE:
================================================================================

1. Hard Refresh Your Browser:
   • Windows: Ctrl + Shift + R
   • Mac: Cmd + Shift + R

2. Check for errors in browser console (F12)

3. Test the API directly (should return JSON):
   http://localhost:8000/api/v1/subscriptions/plans/

4. If API works but admin is blank:
   - Run in command prompt:
     python manage.py collectstatic --clear --noinput
   - Then refresh the browser

5. Check browser's DevTools (F12):
   - Console tab for JavaScript errors
   - Network tab to see if CSS/JS files load

💡 COMMON ISSUES & SOLUTIONS:
================================================================================

Issue: "Module not found: django"
Fix: Make sure to use the full Python path as shown above

Issue: Port 8000 already in use
Fix: Run with different port:
     python manage.py runserver 0.0.0.0:8001

Issue: Database error
Fix: Reset database:
     del db.sqlite3
     python manage.py migrate
     python manage.py createsuperuser (create new admin)

Issue: Static files not loading
Fix: Collect static files:
     python manage.py collectstatic --clear --noinput
